# Worked Examples

A full daily-scope brainstorm run for a **grass-cutting Roblox simulator** (the game discussed when this skill was created). Demonstrates the table output format: ranking rationale, lean overview table, then one compact per-idea table per idea — with exclusivity tags, hybrid tags, and monetization honesty.

Game context used for this run: core loop = unbox weapons with cash → cut grass → sell grass for cash; weapons and grass are color-typed (red/blue/white) with matchup bonuses; tiered grass zones; quest-leveling for equip slots; planned clans/trading/leaderboards; young audience; aggressive monetization; no rebirth.

**Ranking rationale:** Most thematically-exclusive ideas rank highest (Weather through Grass Donation NPC — each only possible because of this game's specific mechanics); semi-exclusive ideas next (Composter, Weapon Crafting — theme-native framing, portable shape); generic-but-effective ideas lowest and honestly tagged (Investor through Battle Pass).

### 1. Weather System

| Field | Content |
|---|---|
| Concept | Daily weather (rain/drought/frost/etc.) shifts grass values and growth rates. |
| Scope fit | Resets every 24h — "what's the weather today?" is a daily ritual. |
| Why exclusive | Only works because grass is color-typed: weather maps to grass colors (rain→blue thrives, drought→red spikes). A one-resource sim has nothing for weather to act on. |
| Strengths | Lawn-theme native; rewards weapon diversity; cheap multiplier tables; event calendar. |
| Risks | One best weather = "bad days"; kids may need a tutorial. |
| Hybrid | mid-term (session planning around the day's weather). |
| Monetization | Forecast reroll, Weather Shield (lock weather), Controlled Climate gamepass. |

### 2. Auto-Mower

| Field | Content |
|---|---|
| Concept | Robotic mower auto-harvests a grass patch offline up to 8h; collect on login. |
| Scope fit | 8h offline timer maps to "set before school, collect after." |
| Why exclusive | A robotic mower collecting grass is inseparable from the grass-cutting theme; no other sim genre does this naturally. |
| Strengths | Theme-perfect; genuine login pull; parallel upgrade track; zero tutorial. |
| Risks | Too strong → replaces active cutting; needs server-side offline sim. |
| Hybrid | mid-term (mower upgrade grind). |
| Monetization | Extra mower slots, premium fuel, cosmetic skins, Lucky Mower gamepass. |

### 3. Garden Plot

| Field | Content |
|---|---|
| Concept | Plant grass seeds (rare drops); grow 4–8h into premium grass; water to speed. |
| Scope fit | Multi-hour grow timers + watering cadence = daily check-ins. |
| Why exclusive | Growing grass from seeds is the inverse of the core loop (cutting) — only a grass game makes planting the hook. |
| Strengths | Idle + planning hybrid; seed rarity = secondary collection goal; bedtime ritual. |
| Risks | Multiple timer mechanics clutter UI; over-monetization → pay-to-win farming. |
| Hybrid | mid-term (planting/harvesting is a mini-session). |
| Monetization | Extra plots, premium seeds, Auto-Sprinkler, Miracle-Gro instant-grow, exclusive seeds. |

### 4. Weed Bounty

| Field | Content |
|---|---|
| Concept | 1–3 daily boss weeds with color-specific weaknesses; drop rare loot. |
| Scope fit | Rotating daily targets — "what's today's bounty?" is a strong daily pull. |
| Why exclusive | Boss weeds needing color-matched weapons only works because of the color matchup system; a generic daily boss is portable, a color-locked weed isn't. |
| Strengths | Theme-perfect; non-violent combat; group bounties tie to clans; TikTok potential. |
| Risks | Boss design/animation work; too hard frustrates kids, too easy bores veterans. |
| Hybrid | mid-term (the fight), long-term (rare-drop collection). |
| Monetization | Bounty Hunter gamepass (extra slot), reroll, Bounty Radar (reveal tomorrow's). |

### 5. Lawn of the Day

| Field | Content |
|---|---|
| Concept | Shared mega-lawn opens 1h daily; compete to harvest the most grass. |
| Scope fit | Time-gated 1h daily window creates urgency and a daily ritual. |
| Why exclusive | A competitive grass-harvesting event is only possible in a grass-cutting game. |
| Strengths | Pulls competitive players daily; clan version = social retention; leaderboard = free marketing. |
| Risks | Server architecture for mass participation; casuals may never engage. |
| Hybrid | long-term (leaderboard/competition grind). |
| Monetization | Extra entries, Golden Scythe (2x harvest), VIP leaderboard tier. |

| Field | Content |
|---|---|

### 7. Mystery Seed

| Field | Content |
|---|---|
| Concept | One free seed per login; grows 24h into a random reward. |
| Scope fit | Combines daily login + 24h timer anticipation in one mechanic. |
| Why exclusive | Seeds growing into rewards is grass-theme-native; the "what grew?" reveal is a grass-game ritual. |
| Strengths | Login + timer anticipation combined; mystery/gacha is exciting; simple to implement. |
| Risks | 24h is long for impatient kids (the retention point); random outcomes disappoint. |
| Hybrid | long-term (legendary chase). |
| Monetization | Extra daily seeds, Blessed Seed (guaranteed rare+), faster growth. |

### 8. Grass Donation NPC

| Field | Content |
|---|---|
| Concept | Daily NPC requests specific grass; donating builds rep for permanent rewards. |
| Scope fit | One donation per day = daily check-in with a relationship progression underneath. |
| Why exclusive | Grass as the donation currency ties to the core loop; "the NPC needs grass" only makes sense in a grass game. |
| Strengths | Feels like helping (good for kids); rep is a long-tail grind; rotating NPCs add variety. |
| Risks | NPC variety/writing demand; kids may find it boring vs combat/collection. |
| Hybrid | long-term (reputation grind). |

### 9. Composter

| Field | Content |
|---|---|
| Concept | Dump junk grass/weapons; 4–6h later get fertilizer that temporarily buffs output. |
| Scope fit | Multi-hour timer = set-and-return; fertilizer is a "use it on login" consumable. |
| Why exclusive | Grass→fertilizer is theme-native, but "convert junk→buff" exists in other sims; framing exclusive, shape portable. |
| Strengths | Gives value to trash items; fertilizer creates a "use it now" login beat; simple risk-free timer. |
| Risks | Less exciting than Investor (no mystery); kids may not grasp composting. |
| Hybrid | short-term (fertilizer use is a quick beat). |
| Monetization | Extra bins, Super Compost speed-up, premium recipes (guaranteed rare fertilizer). |

### 10. Weapon Crafting Station

| Field | Content |
|---|---|
| Concept | Craft weapon crates from grass+cash+essence over 4–6h; recipes unlock via quests. |
| Scope fit | Multi-hour craft timers + a queue = daily return to collect and re-queue. |
| Why exclusive | Grass+essence inputs tie to the core loop, but "craft on a timer" is portable; framing exclusive, shape generic. |
| Strengths | Deepens the core loop; recipe discovery = collection meta; essence drops make every cut a gamble. |
| Risks | Complexity may frustrate kids; too many timers = chore; must not replace unboxing. |
| Hybrid | mid-term (recipe collection), long-term (best weapons). |
| Monetization | Speed-ups, extra queue slots, premium recipes, Master Crafter gamepass. |

### 11. Weapon Investor

| Field | Content |
|---|---|
| Concept | Stash weapons in an NPC rental stand; earn cash+grass interest over 6h. |
| Scope fit | 6h timer maps to "before school→after school" or "lunch→evening." |

### 12. Daily Quest Chain

| Field | Content |
|---|---|
| Concept | 3–5 daily quests in a chain; full-completion streak bonuses stack across days. |
| Scope fit | Resets daily; chain structure extends the daily session beyond a single quest. |
| Why exclusive | Quest chains are portable; grass/weapon-color targets add theme but the shape is generic. |

| Risks | Chore-list feel if too grindy; quest variety is hard to sustain (dev overhead). |

### 14. Streak Calendar

| Field | Content |
|---|---|
| Concept | 7/30-day login calendar with escalating rewards; miss a day = reset (or drop a tier). |
| Scope fit | Pure login-streak mechanic. |
| Why exclusive | Every mobile game has this — zero differentiation. |
| Strengths | Dead simple (8-year-olds get it); near-zero dev cost; baseline retention lift; seasonal calendars keep fresh. |
| Risks | Zero differentiation; drives login not play; entitlement when it "ends." |

### 18. Seasonal Battle Pass — *cross-scope connector*

| Field | Content |
|---|---|
| Concept | 30-day season; earn XP via daily systems; free + premium reward tracks. |
| Scope fit | Not a daily idea — daily systems (quests, bounties, weather) feed its XP; included as a cross-scope connector. |
| Why exclusive | Battle passes are portable; grass-themed seasonal rewards add flavor but the shape is generic. |
| Strengths | Industry-standard; ties all daily systems into one track; visual progress bar is satisfying. |
| Risks | High content demand (new rewards monthly); premium track must not gut the free track. |
| Hybrid | primary: long-term; also: daily (XP source), weekly (season cadence). |
| Monetization | Premium track, tier skips, Season Pass Plus (start tier 10 + bonus XP). |
