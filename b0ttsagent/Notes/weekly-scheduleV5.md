## 🔑 Legend / Key

| Tag | Meaning |
|---|---|
| **POW** | Part of Work — counts toward daily **8h work** total |
| **POF** | Part of Freetime — counts toward daily **8h free** total (Sunday = 16h free) |
| **Sleep** | Separate category — 8h baseline, every day |
| **NR** | Not Required — a recommendation/reminder only; carries **0 scheduled hours** and never enters any total |
| **Freeday exception** | Runs **Mon–Sat**, skipped on **Sunday** (the freeday) |
| **Flex** | Filled block — expands to hit the 8h target (Work flex → 8h POW; Extra Freetime → 8h/16h POF) |
| **Conditional** | Sunlight only — **0–1h**, skipped if enough sunlight was gotten during the 8am Morning Ritual meditation. **Not hard-coded** into POF totals; when taken, it draws down Extra Personal Freetime |
| **Unmask stream** | Both streams (Streaming Normal, Streaming MC Hardcore) are unmask streams |

**Daily targets (Mon–Sat):** 8h Work (POW) + 8h Free (POF) + 8h Sleep = 24h
**Sunday (Freeday):** 0h Work + 16h Free + 8h Sleep (true day off — totally unstructured except lightweight anchors)

**Sunday handling:** Sunday is **excluded from all weekly calculations**. It appears as its own per-day table (Table 8) and as a visible reference column in Tables 9–12 — but every **Weekly Total sums Mon–Sat only**. Sunday never enters the totals.

**Step order:** the **#** column in every per-day table is the task's step number in `Schedule Architecture V4.1.md` (1–21). Days list only the steps that occur that day, in ascending step order.

**Morning Ritual (step 1)** is a single **1.5h capped container**, Mon–Sat:
- 30m Meditation *(daily)*
- 30m Manifestations/Affirmations *(Mon/Wed/Sat only)*
- 15m Clear out air *(per the guide)*
- Remainder = brush teeth, etc. → **15m** on Mon/Wed/Sat, **45m** on Tue/Thu/Fri

## 💡 Insight Highlights

1. **Perfectly balanced Mon–Sat** — every weekday hits exactly 8 / 8 / 8 (POW / POF / Sleep). Sunday sits outside the math as the freeday (0 / 16 / 8), visible in Tables 9–12 but never summed.
2. **Flex time is now nearly flat** — Extra Personal Freetime is **3.33h every Mon–Fri**; **Saturday is the tightest day** at 3.16h (Dehumidifier + Gym + Weekly Review stacked). With MC Hardcore moved off Friday, no single day is the obvious breaking point — pressure is evenly distributed.
3. **Thursday took on the MC Hardcore stream** — moving it off Friday relieved Friday's triple-stack (Skill Study + Gym + stream) and filled Thursday's previously wide-open POF. Thu and Fri are now structural twins: Skill Study + one 2h POF block (stream Thu / gym Fri) + 3.5h flex Work each.
4. **Streaming restructured (both unmask):** Streaming Normal runs Mon/Wed (2h each: 30m plan/prep + 1.5h live); MC Hardcore runs Thursday (2h: 30m prep + 1.5h live). Both are **POF** now. You're live ~**4.5h/week** with ~1.5h prep around it. Sunday's MC Hardcore instance is NR and deliberately unscheduled.
5. **Gaming is work** — Mobile + PC Gaming sit in POW (30m each, Mon–Sat = **6h/week** of market research), each requiring ≥1 new game per week. They come after End of Day Ritual in the arc doc's step order.
6. **Work (flex) = 24.5h — just over half the POW budget.** It's deepest Mon/Wed (5.0h) and shallowest Tue/Thu/Fri (3.5h). The rest of POW is intentional structure: End of Day Ritual 6h, Skill Study 4.5h, Planning + Ideation 6h, gaming research 6h.
7. **Morning Ritual grew to a 1.5h container** (up from 1h in V4) — 30m meditation daily, +30m manifestations Mon/Wed/Sat, 15m clear air, brush teeth filling the rest. That's **9h/week** of morning foundation.
8. **Health investment (Mon–Sat)** = Gym 6h + Morning Ritual 9h = **15h** (+ Skate 1h and Sunlight ≤6h conditional, both outside the counted math).
9. **Sunday = anchors + open water.** Only Breakfast (1h), Moral Code Review (15m), and Skate (1h) are fixed — 13.75h unstructured. Clip Farm (2–3h) and the second MC Hardcore stream hang there as NR options if the day calls for them.
