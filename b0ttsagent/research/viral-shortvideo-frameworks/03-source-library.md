# Source Library — Where This Knowledge Lives (and How to Verify It Yourself)

**Purpose:** every framework in this research traces back to a small set of primary-source wells — and a wider set of context-specific trade-press and verification sources. This file lists every source cited in any of the 10 case studies with full per-source metadata, so any claim in the synthesis can be traced to its exact source without re-reading the case study.

**Per-source metadata** (per the spec): title · URL · source date · source type · FIRST-PARTY (creator's own words) vs SECOND-HAND (analyst/reporter) · MONETIZED (tied to a product the speaker sells) vs INDEPENDENT (no product tied) · `still-current as of 2026?` (YES / NO / PARTIAL / UNCLEAR + reason).

**How to read:**
- Slugs = as in `01-comparison-matrix.md`: `zk` Zach King · `mb` MrBeast · `dm` Dhar Mann · `kl` Keith Lee · `ar` Airrack · `sh` Steven He · `cs` Caleb Simpson · `nd` Nick DiGiovanni · `ss` Sam Sulek · `jh` Jenny Hoyos.
- Each source ID is the citation tag used in the case study (`[S1]`, `[V2025]`, etc.); the case-study files carry the "what it documents" column there (kept here on the source-library side only where needed for cross-creator navigation).
- **Cross-reference** — when seeking a source for any claim in `01-comparison-matrix.md` or `02-recurring-patterns.md`, follow the slug → case-study section `## Source-by-Source Evidence` → the resolution table below for the URL.

## Verifying views & dominance yourself (the spec's measurement protocol)

Every dominance score in this research was reproduced from per-video view-count pulls via `yt-dlp` (the mission's mandated protocol — not eyeballed or estimated from press figures). To re-run:

```bash
# YouTube Shorts (exact counts; tab is reverse-chronological so row order = recency)
yt-dlp --flat-playlist --playlist-end 20 \
  --print "%(view_count)s | %(title).50s" "https://www.youtube.com/@HANDLE/shorts"

# TikTok (exact counts AND dates — dates let you verify the 2021–2026 window directly)
yt-dlp --flat-playlist --playlist-end 20 \
  --print "%(view_count)s | %(upload_date)s | %(title).40s" "https://www.tiktok.com/@HANDLE"
```

**Caveats** (carried from the spec):
- **YouTube flat mode returns no upload dates** (all NA). "Last 20 by position" is the recency proxy — fine for the hit-rate floor. To prove recency of hits on YouTube, pull dates for the newest few videos individually or cite dated third-party coverage.
- **Consistency test floor** — ≥60% of the last 20 eligible public videos exceed 100k views (per-video counts; never a channel-level claim); new-upload exclusion: <7 days old = excluded from the hit-rate computation (TikTok uses upload date; YouTube flat mode = exclude rows 1–2 as the proxy).
- **Channel-size normalization** — raw counts judged against channel size. `jh`'s 1.6% view-to-follower ratio is a verified flag (per her own 0.759 dominance reading, not hand-waved).
- **Reels-only creators** would be marked `verification: PARTIAL — views unverifiable` per the spec — but **the approved 10 all have a TikTok or Shorts presence** where the consistency test runs; no PARTIAL-only creator anchors the shortlist. (The single PARTIAL-verification case, `cs`, has TikTok-primary; the same-day-stale badge confirmation caveat travels to synthesis — see `01-comparison-matrix.md` Table A.)
- **Staleness travel rule** — when re-verifying, treat any 2021 figure (e.g., Dhar Mann's NYT peak / King's 7-10-day cadence) as superseded unless the creator has restated it 2022–2026. The dominant narrative in 2021 always sounds more current than it is; the source date is the truth.
